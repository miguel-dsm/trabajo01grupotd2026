# Trabajo 01 Grupal — Teoría de la Decisión

Este repositorio contiene el **Trabajo 01 de la asignatura Teoría de la Decisión**. En él se desarrollan diferentes ejercicios relacionados con la **toma de decisiones bajo incertidumbre**, utilizando **R** para realizar los cálculos y análisis correspondientes.
El proyecto incluye dos problemas de Teoría de la Decisión bajo Incertidumbre por cada integrante del grupo: un primer problema basado en una tabla de decisión con valores inventados, y un segundo problema que plantea una situación real.
El proyecto incluye dos archivos principales. En el primero de ellos, enunciados.qmd, se presentan los enunciados de los dos problemas junto a cinco preguntas de verdadero o falso para cada uno. En el segundo, soluciones.qmd, se presentan los problemas junto a las soluciones. El primero se resuelve empleando cada función asociada a los criterios de incertidumbre proporcionadas en el archivo teoriadecision_funciones_incertidumbre.R, mientras que el segundo se realiza de forma directa a través de la función que agrupa todos los criterios.
